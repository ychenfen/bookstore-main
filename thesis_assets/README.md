# Thesis Assets

这个目录用于存放论文和答辩演示素材：

- `demo_seed.sql`
  本地演示数据库初始化脚本，包含用户端和管理员端的样例数据。
- `capture_screenshots.mjs`
  自动截图脚本，会导出首页、图书列表、详情页、购物车、结算页、订单页、个人中心以及管理后台截图。
- `THESIS_FIGURE_GUIDE.md`
  论文插图说明，包含图题建议、章节建议与素材使用顺序。
- `latex_figure_snippets.tex`
  论文 LaTeX 插图代码片段，可直接复制到正文中使用。
- `screenshots/`
  截图导出目录。
- `diagrams/`
  论文配图目录，包含总体架构图、数据库 E-R 图、UI 页面关系图、角色功能模块图、用户购书流程图和管理员 CRUD 流程图。
